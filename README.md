# 📊 Smart Attendance System

A web-based Smart Attendance System built using **Python Flask and MySQL**.

The system helps manage students, mark attendance, recognize students using face recognition, generate attendance reports, and manage attendance records from a single dashboard.

---

## 🚀 Features

- 🔐 Admin Login
- 📊 Dashboard
- 👨‍🎓 Add Student
- ✏️ Edit Student
- 🗑️ Delete Student
- 👥 View Students
- 📷 Student Photo Upload
- 🧠 Face Recognition Attendance
- 📝 Manual Attendance
- ✅ Present / ❌ Absent Attendance
- 🔒 Close Attendance
- 🔓 Reopen Attendance
- 📋 Attendance Reports
- 🔍 Search Attendance Records
- 📅 Date-wise Attendance Filter
- 📄 Export Attendance Report to PDF
- 📊 Export Attendance Report to Excel
- 📱 Parent Mobile Number
- 💬 WhatsApp Notification Integration
- 📈 Dashboard Attendance Chart
