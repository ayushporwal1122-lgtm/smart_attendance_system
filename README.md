# Smart Attendance System

A web-based Smart Attendance Management System built using **Python Flask, MySQL, HTML, CSS and Face Recognition**.

The system helps administrators manage students, mark attendance, generate reports and maintain attendance records through a simple web interface.

## 🚀 Features

- Admin Login
- Dashboard with attendance statistics
- Add Student
- Edit Student
- Delete Student
- View Students
- Student Photo Upload
- Face Encoding
- Face Recognition Attendance
- Manual Attendance
- Present / Absent Management
- Close Attendance
- Reopen Attendance
- Attendance Reports
- Search and Filter Attendance
- PDF Report Export
- Excel Report Export
- MySQL Database Integration
- Parent Mobile Number Management
- WhatsApp Notification Integration
- Responsive and Modern UI

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- Flask

### Database
- MySQL

### Other Technologies
- Face Recognition
- OpenCV
- WhatsApp Cloud API
- Chart.js
